Why rayl exists

I got locked out of my own inbox.

I connected an AI assistant to Gmail. It made more API calls than I realized. Google flagged the activity and locked me out. I appealed and eventually got my account back.

Apple Mail had already downloaded the messages I needed. I built rayl to read that local copy. Searches go straight to files on the Mac, so there’s no mail API quota for an assistant to burn through.

The mail was already here.

Permissions and limits

What it honestly can’t do yet.

rayl runs locally and makes no network requests. Your MCP client receives the messages it asks for, so how that client handles them depends on its configuration.

Full Disk Access for reading mail
Grant it to the app that launches rayl to search, read, list mailboxes, or access attachments. Reply drafts use this access to find the original message and Mail Automation to create the draft.
New drafts use Mail Automation
For new drafts only, skip Full Disk Access. Open Mail.app and allow Automation when prompted. Drafts wait in Mail for you to review and send.
Body search is linear and unindexed
Some messages have only headers on disk. In the author’s mailbox, that accounted for 37% of messages.
No cache or index on disk
rayl keeps no persistent cache or index. Drafts and attachments you explicitly save are written to disk.

MCP tools

Seven tools for Apple Mail.

search_mail
Find messages by subject, sender, recipient, body text, mailbox, flags, or date.
read_message
Read a message’s headers and available body.
list_mailboxes
Find mailboxes and labels to filter by.
mail_status
See which accounts are loaded and what’s readable.
draft_message
Save a new draft to Mail’s Drafts folder.
draft_reply
Save a threaded reply draft.
save_attachment
List attachments or save them to files.

Install

Install rayl.

A Rust binary for macOS. It speaks MCP over stdio and is released under the MIT license.

Prebuilt binary · macOS universal
installer="$(curl -fsSL https://raw.githubusercontent.com/oti-adjei/rayl/main/install.sh)" && sh -c "$installer"

The installer verifies the release checksum and puts rayl in ~/.local/bin. Run ~/.local/bin/rayl doctor after installing.

macOS binary downloads: Unavailable · crates.io downloads: Unavailable

With a Rust toolchain, you can also clone and build from source.

Build from source
git clone https://github.com/oti-adjei/rayl
cd rayl
cargo build --release
./target/release/rayl doctor

Register rayl with your client using the absolute path to the binary. If you want to read mail, check that doctor reports direct read path available. For new drafts only, open Mail.app and allow Automation on first use.

Claude Code
claude mcp add rayl --scope user -- "$HOME/.local/bin/rayl" serve
Pi
pi mcp add rayl -- "$HOME/.local/bin/rayl" serve
pi mcp list
Configure Claude Desktop

Add this entry to claude_desktop_config.json in ~/Library/Application Support/Claude/. Replace the example path with the absolute path to your binary.

{
  "mcpServers": {
    "rayl": {
      "command": "/absolute/path/to/rayl",
      "args": ["serve"]
    }
  }
}
